# v0.44.0 — Sistema de plantillas comerciales (página pública configurable)

**Fecha**: 2026-08-22

## Qué se implementó
Se ejecutó en código `PLANTILLA_COMERCIAL_EMPRESA_STANDARD.md`:
un sistema por el cual cada empresa que compra un espacio en Newen construye su
**página comercial pública** sin tocar código, con un único objeto de configuración
(`TenantSiteConfig`) por organización.

## Motor de configuración (`lib/public-site/`)
- `types.ts` — `ColorPalette`, `TypographySystem`, `BrandAssets`, `LayoutConfig`,
  `ComponentVariants`, `TenantSiteConfig`, secciones y metadatos.
- `defaults.ts` — default de Newen (editorial, cálido-humanista, Cormorant Garamond +
  Inter), ejemplo `ESPACIO_CRITICO_SITE_CONFIG` (§5 del estándar), metadatos de las 5
  plantillas, 10 paletas prearmadas y las 8 secciones disponibles.
- `normalize.ts` — validador/normalizador (reemplaza zod, que no está en el proyecto):
  toma cualquier objeto parcial/corrupto y devuelve una config completa con fallbacks
  (§4). Incluye luminancia/contraste para la regla WCAG AA (§2.1).
- `css.ts` — genera `--site-*` variables CSS y la URL de Google Fonts.
- `from-org.ts` — `buildSiteConfig(org)`: si hay `site_config` JSONB lo normaliza; si no,
  mapea los campos legacy (primary/accent/font/logo) para que ningún espacio se rompa.

## Componentes (`components/public-site/`)
- `primitives.tsx` — botones (solid/outline/ghost con escala de padding), tarjetas,
  badges (pill/square), eyebrows y encabezados. **Cero colores/fuentes/radios hardcodeados**.
- `sections.tsx` — secciones data-driven desde la org: servicios, metodología, equipo,
  testimonios, contacto, turnos, catálogo, próximos. Orden según `layout.sections.order`.
- `templates.tsx` — las **5 plantillas base** como componentes de LAYOUT puro:
  Editorial, Vitrina, Panel comercial (sidebar), Minimal/Portfolio, Modular.
  El logo se usa SOLO en header (zona 1) y footer (zona 2, chico + opacidad) (§2.3).
- `SitePage.tsx` — wrapper raíz que aplica las variables CSS y elige plantilla.

## Integración
- `app/e/[slug]/page.tsx` — reescrita: renderiza con `SitePage` + `buildSiteConfig(org)`;
  `generateMetadata` para ogImage (zona 3). Mantiene `OjoVistaEmpresa`.
- Migración `spec/init_v0.44.0_site_config.sql` — `ALTER TABLE organizations ADD COLUMN site_config JSONB`
  (idempotente, NO toca RLS).
- `app/api/organizations/route.ts` (PATCH) — acepta `site_config`, normalizado en el servidor.
- **Editor** `app/(empresa)/empresa/public-site/page.tsx` + `editor.module.css` — elige
  plantilla, paleta (presets + colores custom), tipografía, escala, secciones (toggle +
  orden), hero, CTA, radio y sombra; **preview en vivo** con las fuentes reales; guarda y
  enlaza a "Ver página pública".
- Accesos: botón "Página comercial" en el topbar del panel, ítem "Página Comercial" en el
  sidebar (nuevo ícono SVG globo `SidebarIcon "pagina"`) y pestaña "Página" en el nav inferior.
- **Onboarding**: tras crear el espacio (`app/empresas/crear`), se redirige a
  `/empresa/public-site?bienvenido=1` (lo primero que ve la empresa tras comprar).

- Preview real en browser con la config de Espacio Crítico: plantilla Editorial, Panel
