# v0.36.0 — Fix: recursión infinita en RLS de organization_members

**Fecha**: 2026-08-20
**Tipo**: fix
**Autor**: Clr. Ari Mangini (asistido por DeepSeek V4 Pro — GitHub Copilot)

---

## CONTEXTO

Al dar de alta un cliente en el panel Empresa: `Error al cargar: infinite recursion detected in
policy for relation "organization_members"`.

**Restricción dura**: prohibido quitar cualquier RLS. El fix corrige la política sin desactivar RLS.

## CAUSA

La política `members_read_own` de `organization_members` se referenciaba a sí misma dentro de su
propia cláusula `SELECT`:

```sql
FOR SELECT USING (user_id = auth.uid() OR EXISTS (
  SELECT 1 FROM organization_members me
  WHERE me.organization_id = organization_members.organization_id AND me.user_id = auth.uid()
));
```

La subconsulta lee `organization_members` dentro de la política de `organization_members` →
recursión infinita. Se disparaba al insertar un cliente porque la política de
`organization_clients` consulta `organization_members`.

## FIX

```sql
DROP POLICY IF EXISTS "members_read_own" ON public.organization_members;
CREATE POLICY "members_read_own" ON public.organization_members
  FOR SELECT USING (user_id = auth.uid());
```

Cada usuario lee su propia membresía. Las demás políticas (`organizations_*`, `clients_*`,
`employees_*`, `tasks_*`, `derivaciones_*`, `mensajes_*`) siguen consultando `organization_members`
pero ya no son recursivas.
