## CONTEXTO

Crear una cuarta área en newen, distinta de profesional/admin/consultante: un acceso para
**empresas que pagan por un espacio comercial** dentro de la plataforma, enlazado (si se paga)
a un **campus digital** (ya maquetado, aún no desarrollado).

Caso concreto de validación: **Espacio Crítico** (counseling organizacional). La estética de su
espacio público es la de su web (oscura, dorada, serif Cormorant Garamond). El panel privado es
una **consola admin multicliente**: selector de cliente, KPIs, sistema de 6 fases
(Diagnóstico→Mantenimiento), informes, agenda, seguimiento por tareas, empleados con ficha
personal y derivación a counselors de newen con mensajería interna.

## PLAN

## PROBLEMAS

- **42703: column `derivaciones.organization_id` does not exist** — la tabla `derivaciones`
  ya existía en newen (v0.15.0, derivaciones entre counselors) sin esa columna, y el
  `CREATE TABLE IF NOT EXISTS` la saltó. Solución: renombrar las tablas nuevas a
  `organization_derivaciones` / `organization_mensajes`, limpiar la huérfana `mensajes` y
  hacer las policies idempotentes para poder re-ejecutar el script.

## DECISIONES

- Estética del área Empresa con CSS Module propio (`empresa.module.css`), separado de los
  tokens globales de newen (oscura/dorada, serif Georgia como placeholder de Cormorant).
- Ruta pública `/e/[slug]` (con barra final en la lista pública del middleware para no
  colisionar con `/empresa`).
- RLS solo en tablas nuevas (no se tocan tablas existentes).
- Derivación inserta en `derivaciones` (mensajería `mensajes` queda lista para la próxima
  iteración).
