# v0.43.1 — Campus fiel a la maqueta (CSS module con animaciones)

**Fecha**: 2026-08-22

## Problema
El usuario marcó que el campus "imita pero no es igual": los botones no tenían animación y la
maqueta se veía más prolija. Causa: se usaban estilos inline (no soportan `:hover` ni `transition`).

## Solución
Se creó `campus.module.css` portando fielmente `campus-maqueta.css` y se reescribió `page.tsx`
usando las clases:

- **Botones**: `transition: transform .2s, box-shadow .2s, background .2s` + `:hover { translateY(-1px) }`.
  - `.primary`: verde `#3e5c4d`, sombra `0 10px 28px rgba(62,92,77,.14)`, hover `#35503f`.
  - `.secondary`: blanco, borde terracota `#d8baa6` (no gris), hover `#faf6f1`.
  - `.neutral`: `#f7f6f2`, hover `#eef1e8`.
- **Sidebar**: links `padding 14px 16px`, radius 14, hover/active `#f0efe8`, `transition: background`.
- **Stats hero e investigación**: números terracota `#c87d55`, tamaño 2rem, weight 800.
- **Biblioteca**: layout split `1.3fr/0.7fr` como maqueta — course-card "Material destacado" con
  badge "Nuevo", lista de módulos, botones "Explorar biblioteca"/"Mis descargas"; sidebar con
  Categorías + Lectura actual con barra de progreso. Debajo, catálogo real de cursos (buscable).
- **Encuentros**: filas con hover `translateY(-2px)` + sombra.
- **Modales**: animación `modalIn` (fade + slide), focus en inputs con borde verde.
- **Fuentes**: `@import` de Inter + Merriweather (igual que la maqueta).
