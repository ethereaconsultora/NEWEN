## CONTEXTO

Se decide pausar momentáneamente el espacio comercial (solo quedan migraciones SQL por correr, sin
código pendiente) para avanzar con el campus digital. Diseño: videollamada **Daily.co** para el área
de profesionales (1-1) y **Jitsi Meet + OBS** en servidores pagos para el campus (fase posterior).
Paso 1 acordado: campus real con salas funcionando, sin infraestructura paga todavía.

## PLAN

1. Schema `campus_*` en Supabase con RLS (patrón seguro por membresía, sin tocar RLS existente).
2. Página `/empresa/campus` real con el diseño de la maqueta (tema claro verde salvia, nav lateral:
   Inicio · Mi recorrido · Biblioteca · Comunidad · Supervisión · Prácticas · Encuentros).
3. Salas de video:
   - Encuentros grupales → Jitsi en iframe (POC con `meet.jit.si`, luego Hetzner vía env).
   - Sesiones 1-1 → Daily.co Prebuilt (room creada por API).
4. En `/panel` (profesionales), entrada "Sala 1-1" que abre una llamada Daily.co.

## VARIABLES DE ENTORNO (configurar en Vercel / .env.local)

- `NEXT_PUBLIC_DAILY_DOMAIN` → ej: `newen` (dominio de Daily.co)
- `DAILY_API_KEY` → API key del panel de Daily.co (solo servidor)
- `NEXT_PUBLIC_JITSI_BASE` → `https://meet.jit.si` (POC) o tu instancia de Hetzner
